# 404 恢复与首页精简（2026-10-10）

Web v2.0.0-beta.2。首页移除“ROSEMARY DESIGN SYSTEM”文字、圆点装饰及同排重复版本标记；页头版本入口保留。404 恢复页面只提供“返回首页”，无组件库或案例库等无关操作。

## 实现

NotFoundPage 为应用与静态错误文档共用的唯一内容实现。未知栏目、未注册组件/案例、畸形编码、多余路径和错误物理路径均显示错误页，不以首页掩盖不存在的请求。构建生成 dist/404.html，正文与恢复链接不依赖应用 JavaScript。其主题及减少动态效果从现有设置读取。恢复入口使用 /#/overview，确保离开错误的深层地址。

两台现有宝塔 Apache 站点均已配置 ErrorDocument 404 /404.html。正常根文档返回 200；不存在的深层路径与资源返回 404，同时显示品牌页面；直接访问 /404.html 返回 200。hash 路由错误由应用显示，浏览器对根文档的 HTTP 请求仍为 200。保留已有证书、HTTP→HTTPS 规则及前一发布目录，并保留旧散列资源，供发布前已打开的网页完成载入。
