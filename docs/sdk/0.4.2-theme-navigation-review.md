# SDK 0.4.2 theme and navigation review

Forma specification remains 1.2.0. This compatible SDK patch adds `moon`, `theme-system` and `globe` to the shared functional icon source (74 icons), regenerates SVG/normalized geometry for React, Compose, SwiftUI and Flutter, and uses the same source in the portal. Functional icons and their download ZIP include MIT licensing. Existing 0.4.0 and 0.4.1 tags, assets and historical verification reports remain unchanged.

The portal provides explicit light/dark/system appearance choices on wide screens and one accessible cycle button on narrow screens. System mode observes the operating system preference and persists the selected mode. The language dropdown keeps a globe and disclosure cue; the language control currently exposes only the actual Simplified Chinese content. The navigation specification requires real translated labels and specification/case-study content before offering another locale; this release does not claim multilingual translation. Wide language/theme outer containers both measure 48px; narrow containers both measure 44px high, with 56px width for the language dropdown.
