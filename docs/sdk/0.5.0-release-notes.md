# Rosemary SDK 0.5.0 — Release candidate

对应规范：Rosemary Forma 1.3.0。正式发布尚未执行。

- 45 色完整语义主题：导航/顶栏、内容/内嵌/浮层、输入填充与焦点轮廓、当前导航及配对内容色。
- 门户和 Web 共用确定性 HCT 配方；沉静/鲜亮、明暗主题同时生成。大面积表面限制彩度，图片与 HEX 共用约束。
- React、Compose、SwiftUI、Flutter 采用新表面及输入层级，保留键盘、高对比、受控状态与系统偏好。
- 全端可导入完整明暗 JSON；Web 提供无 DOM 依赖的配方生成与显式旧主题迁移。
- 统一网格、图标尺寸和导航选中规则，更新规范、源码消费与发行清单。

- 四端字段要求与邻近验证插槽：首次非空脱焦、后续动态检查、清空重置、IME 组合阶段抑制反馈；统一创建密码规则。
- 输入移除常驻底线，以紧贴 1.5 细轮廓表达焦点；下拉头部与选项连续展开，关闭期间不可操作。
- 共享物理按压／回弹参数、180ms 非线性宽度与滑块过渡，以及系统／宿主减少动态行为。
- 各端样例使用提前显示的字段要求，替换空值即报错的旧用法。新增 API 均为可选参数；宿主仍控制值与提交。

接入说明：[字段校验](input-validation.md)、[交互](interaction.md)。

迁移：完整 24 色对象不再符合 45 色 schema；详见 [迁移指南](0.5.0-migration.md)。33 组件 ID 与 74 图标不变。

发行前需填写：最终 main SHA、四条工作流及七份 CI artifacts、实际运行的目标矩阵、未测系统/辅助技术、独立消费者验证、release-manifest.json 与 SHA256SUMS。仅对精确提交的成功证据标记通过。模拟器/调试样例不声称签名真机或商店分发。

准备的产物：tokens/icons/react tgz；Compose Maven ZIP、AAR、sources JAR、样例 APK；SwiftPM source 与 unsigned simulator sample；Flutter source 和 Android/iOS simulator/Web/macOS/Windows/Linux 消费者产物。不发布 npm、Maven Central、pub.dev，也不自动创建正式 tag。
