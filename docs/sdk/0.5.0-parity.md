# SDK 0.5.0 门户一致性修订

修订基于门户最终 CSS 级联与实际动效执行路径，不把被覆盖的旧底线、旧填充或旧 range 绘制作为标准。

- 共享组件维度明确按钮 13px/1.4、15px 水平内边距、输入 16px/1.5、标签 13px，以及滑块 4px 轨道、16px 圆钮与 8px 端点。React 默认按钮桌面 40px，窄屏/触控 44px；原生保留至少 44 逻辑单位命中区及系统文字缩放，不为截图缩小触控范围。文字和配色按相同角色映射。
- 展开中的触发器和列表使用 fieldHover，关闭/只读/禁用状态使用对应表面；次级按钮使用 fieldFill/ink。弹层最大高 340 逻辑单位，连接边不留缝，保留浮层阴影及高对比边界。
- 从门户 motion-physics.js 的 cssEasing 直接生成进入/退出各 41 个采样点。四端以相同分段线性采样驱动下拉；Flutter 与 SwiftUI 头部的圆角、箭头与面板共用进度，避免独立补间滞后。取消、反向与减少动态路径保留。
- 去掉 SwiftUI 整按钮按下 75% 不透明度，以及 Flutter 按下时额外的文字透明度变化；仍使用原有按压与释放弹簧。Flutter 键盘按压持续到松键，Space 在松键激活，Enter 在按下激活，重复键不重复提交。
- React 下拉在支持时进入原生 popover 顶层，避免被祖先裁切；保留不支持环境的固定定位回退和继承主题。字段轮廓读取四个独立圆角。按钮尺寸观察同时覆盖显式宽度、内容更新和中断重定向，按压不改变布局锚点。
- React 文本框通过显式 Web Animations 描边插值，避免初次聚焦的 CSS 状态在首帧合并而直接显示完整描边；起点仅在上下两边，220ms 扩展合拢，失焦 90ms 淡出。减少动态时立即显示完整轮廓。单选／复选使用 0.9 标记按压缩放与欠阻尼释放弹簧，文字和点击区域不随之缩放；四端共享该参数。
- 原生滑块取消默认可见的加减按钮，保留受控值、方向键、辅助功能增减/设值、拖动及提交。程序设值平滑，拖动直接跟手。

## 验证

共享测试把生成的每一个下拉采样点与门户实际物理模型逐点比较。各原生适配器测试采样插值。Flutter Widget 回归在动画中点同时读取头部旋转矩阵与列表揭露裁切，验证两者不是两个动画；另验证键盘按压保持、滑块几何/键盘/语义。Compose 设备用例验证去掉视觉加减按钮后仍可语义设值与键盘调节。Web 在三种引擎中对照打包门户的真实默认按钮计算样式，并验证滑块、顶层列表及曲线；另采集真实文本框中间描边帧、单选／复选缩小和超过 1 的释放回弹帧，避免把最终静态外观误当成动效通过。Flutter 同样验证标记缩放及文字位置稳定。检查失败或跳过不作为通过。

最终 CI、工作流矩阵与产物来源由 Release 的 release-manifest.json 记录，不用历史提交或本地包代替。原生字体回退、光栅化和窗口阴影由平台适配；这不是跨系统逐像素、逐帧完全相同的认证。真实 Safari、目标真机、最低系统和人工读屏覆盖仍需单独验收。固定采样轨迹和默认几何通过，不等于 33 个组件的所有状态都已完成视觉认证。
