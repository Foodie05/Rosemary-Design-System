# SDK 0.5.0 交互与表面

参数源是 `design/interaction-motion.json`；`pnpm design:generate` 输出 TypeScript、Kotlin、Swift、Dart，`pnpm design:check` 检查漂移。SDK 版本为 0.5.0，规范版本为 1.3.0。

- 输入默认填充，无常驻底线。聚焦绘制向内 1.5 的细轮廓，只在上下边按点击的横坐标投影起笔，向左右展开；键盘从中点开始。展开 220ms，失焦整体 90ms 淡出；错误覆盖为危险色，不改变布局。
- 按压目标 0.974；按压刚度 1800、阻尼比 1，释放刚度 800、阻尼比 0.39，质量均为 1。快速反向从当前状态接续；取消不提交，卸载释放动画资源。选择触发器不独立缩放，以免与展开区域割裂。
- 下拉触发器与列表共用填充、相同宽度和连续接缝，贴合触发器向下揭露；空间不足向上。进入 240ms，退出 180ms，关闭中的内容不可操作；语义状态先更新，不等动画结束。
- 按钮宽度和程序设定的滑块绘制位置使用 180ms、`cubic-bezier(.2,.8,.2,1)` 快速收敛。受控数据和辅助技术值立即更新，拖动直接跟手。原生滚动容器和文字缩放遵循平台约束。
- 减少动态由系统或宿主任一启用即生效：直接呈现目标状态，不创建缩放或揭露。高对比／强制颜色可以恢复系统完整边界。明暗主题按语义色配对，不能直接反相。

搜索应按范围选型：`Search` / `RosemarySearch` 默认 inline 模式，用于当前集合，保留当前结果与焦点上下文；宽屏且高频可默认展开，或关闭 `defaultExpanded`（React）／`initiallyExpanded`（原生）显示紧凑入口。`presentation` 的 dialog 模式使用 SDK 自己的模态层，适合全局检索；Esc 关闭并回到入口，保留查询。inline 的 Esc 先请求清空，再在空值时收起。移动端缩窄不能改变搜索范围，响应式断点由宿主按实际容器决定。语言选择只在确有多种语言可切换时出现；主题偏好推荐一个至少 44×44 的目标图标按钮。SDK 的图库保留多状态切换控件供验收，不是业务顶栏必须照搬的模板。

字段规则和验证插槽见 [字段校验](input-validation.md)。平台求解器与抗锯齿存在差异，验收共享行为和几何，不承诺逐帧像素完全相同。
