Code/functional icons use MIT; names, five badges and official raster artwork use the separate root brand policy.

Targeted 0.4.1 changes and executed local checks are recorded in [0.4.1 consistency review](0.4.1-consistency-review.md); The additive 0.4.2 icons and portal controls are recorded in [0.4.2 theme/navigation review](0.4.2-theme-navigation-review.md); final installation provenance must come from the new exact-main CI Release.

All four SDK candidate workflows succeeded for candidate branch head `a1a44ec`; native PR artifact provenance records the actual synthetic merge `f20d31cc570ee270fbcd43b1b3e462b1ff079b5c`, matching its GitHub build SHA; this is a recorded candidate baseline, not the final release SHA. The bundled Vigilo resource is now generated byte-for-byte from the canonical theme. Its actual installed APK/main startup, archive-consumer regressions and 320 px date layout were additionally verified locally; the final portal passed offline/static/browser/source-ZIP checks. Integrated release acceptance is defined by the exact-main CI gate. Installation provenance is the final Release's `release-manifest.json` and `SHA256SUMS`, which record the exact main SHA, workflow runs and actual package bytes without requiring a documentation commit to name itself.

Executable shared entry points: `pnpm design:check`, then `pnpm build:shared` before `pnpm test:shared`, `node scripts/check-shared-consumer.mjs`. Web entry points are documented in `packages/react/README.md` and `examples/react-gallery/README.md`. Do not turn file counts/export counts into behavioral acceptance claims.

Automated 200% root font-size and 390 px viewport checks passed in the three Playwright engines. Manual acceptance is not complete: real Safari, real devices/touch input, VoiceOver/NVDA/TalkBack, platform text scaling and visual review across the latest two stable browser majors. Playwright WebKit is an engine test rather than a real Safari result. An unexecuted platform/assistive-technology path must remain explicitly unverified.

The historical 61-component prototype is not the SDK catalog. Selected old logic may be adapted; old system picker/spinner visuals and old themes are not restored. This implementation starts from the latest portal specification and includes installable private-distribution artifacts, controlled consumer examples and CI rather than a public registry release.
