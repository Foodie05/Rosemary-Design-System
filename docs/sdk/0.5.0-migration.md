# SDK 0.5.0 / Forma 1.3.0 迁移

0.5.0 是本轮发布候选。当前最后正式发布版仍为 v0.4.2；候选安装包须来自本轮实际 CI 或源码构建。不要下载不存在的 v0.5.0 资产。

## 不兼容变化

完整主题从 24 扩展为 45 色（token schema 2）；`RosemaryColors` 完整构造、主题 JSON、`toMap()` 和 CSS 变量均包含新角色。新增导航、顶栏、内容组、内嵌、浮层、输入表面与配对内容色。旧 24 色对象需要显式迁移；不静默填出声称已验收的完整主题。Web 可用 `migrateLegacyTheme(old, 'light')` 取得默认新增表面后逐项替换，并检查诊断；原生先合并新版默认配方再导入完整 JSON。

默认配色来自受面积约束的 HCT 配方，旧截图与颜色字面值不再是新标准基线。输入、选择、卡片和浮层消费新角色；自定义局部覆盖需要一起调整相关容器与内容色。

## 统一配方交换

门户色彩工作台导出的 `colors.light/dark` 与 `themes.light/dark` 均含 45 色。JSON 值必须为不透明 sRGB `#RRGGBB`。键名为 kebab-case；Web 运行时对象采用 camelCase。缺角色、未知角色、错误颜色或缺少某个模式都应报错。

```tsx
import {createColorScheme,generateColorRecipe,importColorScheme} from '@rosemary-ui/tokens';
const scheme=createColorScheme({seed:'#24675E',mood:'calm'});
<ThemeProvider scheme={scheme} mode="system">{app}</ThemeProvider>
// importColorScheme(JSON.parse(exportedJSON)) 也可读取门户导出。
```

```kotlin
val scheme = RosemaryColorScheme.fromJson(exportedJSON)
RosemaryTheme(scheme = scheme, mode = RosemaryThemeMode.System) { AppContent() }
// 单模式：RosemaryColors.fromHex(complete45RoleMap)
```

```swift
let scheme = try RosemaryColorScheme(json: data)
AppContent().rosemaryTheme(scheme, mode: .system)
// 单模式：try RosemaryTheme(hex: complete45RoleMap)
```

```dart
final scheme=RosemaryColorScheme.fromJson(jsonDecode(exportedJSON));
RosemaryTheme(scheme:scheme, mode:RosemaryThemeMode.system, child:app);
// 单模式：RosemaryColors.fromHex(complete45RoleMap)
```

显式 `colors` 覆盖高于 scheme；未指定 scheme/mode 的局部主题继续继承父级。scheme 同时保留明暗两套值，跟随系统时不能固定为导入时的某一个模式。原生不内置图片文件读取、网络上传或 HCT 近似计算；宿主可消费门户/Web/构建流程生成的同一 JSON。

## 保留的行为

33 个基础组件 ID、74 枚图标、宿主受控状态、本地 Gregorian 日期时间、CN/EN 状态文案、RTL、减少动态及系统能力边界继续保留。焦点样式改变不允许删除焦点语义；强制颜色与高对比模式保留明确边界。
