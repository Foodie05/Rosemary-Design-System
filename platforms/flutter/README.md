# Rosemary Flutter SDK

Version 0.3.0-prototype.2. All 61 component APIs and host examples are implemented; full-library Beta acceptance is pending.

Read [integration guide](../../docs/native/flutter-sdk.md), [API catalogue](../../docs/native/api.md) and [release gates](../../docs/NATIVE-SDK-DESIGN.md). Run `npm run check:native` from the repository root. Build receipts are in `docs/native-checks.json`; device/UI checks and manual VoiceOver/TalkBack checks are separate gates.

Not published to a package registry. Minimum OS versions are API targets, not claims of full device coverage.
