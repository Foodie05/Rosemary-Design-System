# @rosemary-ui/icons 0.4.0

71 original functional icons, MIT licensed. Import `iconNames`, `IconName`,
`iconMarkup`, `iconMetadata`, `iconGeometry`, and `getIconSvg(name)`.
SVG source files are available through `@rosemary-ui/icons/svg/<name>.svg`.

Use `iconMarkup` in an SVG with viewBox `0 0 24 24`, no fill, currentColor
stroke width 1.6 and round caps/joins. Decorative SVGs are aria-hidden; action
names belong to the actual button or link. Native platforms use generated
M/L/C/Z commands with identical geometry. Official logos/product badges are
brand assets and are not part of this functional icon package.

This package is locally installable and is not published to a public registry.
